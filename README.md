# Inventory Management System

## Overview
A relational database project developed using MySQL to manage products, inventory, customers, and transactions.

## Features
- Product Management
- Inventory Tracking
- Customer Records
- Sales Transactions
- Revenue Analysis
- Low Stock Detection

## Concepts Used
- Primary Keys
- Foreign Keys
- Joins
- Views
- Triggers
- Stored Procedures
- Aggregate Queries
- Subqueries

## Technologies
- MySQL
- SQL
